# 🌐 Web Technology Lab

## 📋 About This Repository

This repository contains all the lab experiments and practice programs for the **Web Technology Lab** course. Each experiment is organized in its own folder with a dedicated `README.md`, source files, and the topics covered.

## 🚀 How to Use

1. **Clone the repository**
   ```bash
   git clone https://github.com/Abin-Shaji-Thomas/Web-Technology-Lab.git
   cd Web-Technology-Lab
   ```

2. **Navigate to any experiment folder**
   ```bash
   cd Experiment-1
   ```

3. **Open any `.html` file in your browser**
   ```bash
   # On Linux:
   xdg-open Lab-Excercise1.html
   ```
