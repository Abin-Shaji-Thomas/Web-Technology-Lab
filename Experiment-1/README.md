## 🏷️ HTML Tags & Concepts Covered

| Category | Tags / Concepts |
|----------|-----------------|
| Page Structure | `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`, `<title>` |
| Headings | `<h1>` `<h2>` `<h3>` `<h4>` `<h5>` `<h6>` |
| Text Elements | `<p>`, `<br>` |
| Text Formatting | `<strong>`, `<em>`, `<mark>`, `<sub>`, `<del>` |
| Semantic | `<cite>`, `<blockquote>`, `<abbr>` |
| Media | `<img>` |
| Inline CSS | `background-color`, `color`, `text-align`, `padding`, `border` |
